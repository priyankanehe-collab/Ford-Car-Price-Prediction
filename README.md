
## 📌 Project Overview

This project focuses on predicting the price of Ford cars using Machine Learning regression techniques.  
The model learns patterns from historical car data such as year, mileage, engine size, fuel type, and transmission.

This project demonstrates an end-to-end ML workflow suitable for entry-level AI/ML roles.

---

## 📊 Dataset

- Dataset: Ford Car Price Dataset
- Target Variable: Price
- Features include:
  - Model
  - Year
  - Mileage
  - Engine Size
  - Fuel Type
  - Transmission
